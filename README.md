# Velqora Digital Website

## Structure

velqora-digital/
- index.html                → Brand homepage
- site.css                  → Shared brand/policy styles
- privacy.html
- refunds.html
- terms.html
- contact.html
- shaadi-budget-control/
  - index.html              → Product #1 landing page
  - style.css
  - script.js
  - assets/

## Future products

Add each new product as its own folder:

product-2/
  index.html
  assets/

This keeps the Velqora brand site clean while every product gets a dedicated landing-page URL.

## GitHub Pages

Publish the repository root with:
Settings → Pages → Deploy from branch → main → / (root)
